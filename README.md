# ЛР 9. Классификация

Модель оценивает вероятность того, что квартиру в Астане сдадут за 14 дней (`rented_14 = 1`). Сервис объявлений показывает арендодателю подсказку: «скорее всего, квартира сдастся за две недели» или «есть риск, что не сдастся, проверьте цену и добавьте фотографии».

Данные лежат в `data/astana_rent_class.csv`. Это 600 объявлений за август и сентябрь 2026 года. Признаки модели это район, число комнат, площадь, этаж, этажность, год постройки, мебель, расстояние до центра, цена и число фотографий. За 14 дней сдаётся 34 % квартир.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # на Windows: .venv\Scripts\activate
pip install -r requirements.txt jupyter
python src/train.py                # пишет metrics.json и models/model.joblib
```

Исследование для шагов 2–7 лежит в `notebooks/lab9.ipynb`. Запускайте его целиком через Kernel, затем Restart & Run All.

## Структура

| Путь | Что это |
|------|---------|
| `data/astana_rent_class.csv` | данные |
| `notebooks/lab9.ipynb` | исследование по шагам 2–7 |
| `src/train.py` | обучение модели по `params.json` |
| `params.json` | модель, C, веса классов и порог |
| `metrics.json` | метрики, их пишет `train.py` |
| `models/` | обученная модель, в Git не хранится |
