# ЛР 9. Классификация

Модель оценивает вероятность того, что квартиру в Астане сдадут за 14 дней (`rented_14 = 1`). Сервис объявлений показывает арендодателю подсказку: «скорее всего, квартира сдастся за две недели» или «есть риск, что не сдастся, проверьте цену и добавьте фотографии».

Данные лежат в `data/astana_rent_class.csv`. Это 600 объявлений за август и сентябрь 2026 года. Признаки модели это район, число комнат, площадь, этаж, этажность, год постройки, мебель, расстояние до центра, цена и число фотографий. За 14 дней сдаётся 34 % квартир.

## Эксперименты

Эксперименты сравниваем только по `cv_f1`. Тест для выбора не используем.

| Ветка | Параметры | cv_f1 | cv_roc_auc | test_precision | test_recall | Решение |
|-------|-----------|-------|------------|----------------|-------------|---------|
| main | logreg, threshold=0.5 | 0.5801 | 0.7918 | 0.6154 | 0.4706 | базовая |
| exp/balanced | logreg, class_weight=balanced | 0.6350 | 0.7947 | 0.5588 | 0.7451 | слита, версия `v1.0` |

С весами классов модель чаще говорит «сдастся». Recall на тесте вырос с 0,47 до 0,75, precision упал с 0,62 до 0,56. ROC-AUC почти не изменился. Веса классов не улучшают порядок квартир по вероятности, они сдвигают прогнозы в сторону класса 1, как порог 0,3 в шаге 6.

## Как пользоваться моделью

```python
import joblib, pandas as pd
model = joblib.load("models/model.joblib")
flat = pd.DataFrame([dict(rooms=2, area=60, floor=5, floors=12, year=2015,
                          dist_center=3.0, price=270000, photos=12,
                          district="Есиль", furniture="yes")])
for price in [240000, 270000, 300000, 330000]:
    flat["price"] = price
    print(price, model.predict_proba(flat)[0, 1].round(2))
```

| Цена, тг | Вероятность сдать за 14 дней |
|----------|------------------------------|
| 240 000 | 0,87 |
| 270 000 | 0,72 |
| 300 000 | 0,50 |
| 330 000 | 0,27 |

Двухкомнатная квартира 60 м² в Есиле при цене 270 тыс. тг сдастся за две недели с вероятностью 0,72, при 330 тыс. только с вероятностью 0,27.
